# DealScope — Claude Code Project Guide

Flask app for US rental investors: type an address, get the price a whole home can support (PITI break-even, all-in break-even, target for a cash-flow goal). Public repo, deployed on Vercel.

## Read first
1. `intent.md` (why) → 2. `spec.md` (requirements `FR-`/`OPS-`, formulas, API, decision log) → 3. `plan.md` (tasks, each with a "Done when") → 4. `docs/ai-sdlc.md` (task loop, human gates, guardrails).
If the spec is silent or contradicts itself, record an open question and stop; do not invent behavior.

## Commands
```bash
make install   # .venv + dependencies
make check     # ruff lint+format, secret scan, pytest with coverage ratchet, compile (what CI runs)
make scan      # secret scan only; make hooks enables the pre-commit scan for this clone
make audit     # pip-audit
make smoke URL=https://dealscope-beige.vercel.app
```
Run one test: `python -m pytest tests/test_analysis.py -k price`. Slash commands: `/plan-task`, `/next-task`, `/verify`, `/spec-sync`, `/spec-interview`, `/secret-scan`. Subagents: `spec-reviewer`, `security-reviewer`.

## Workflow
Explore → plan (skip if the diff fits in one sentence) → write the failing test → smallest change → `make check` → independent review → PR. `main` is protected: branch, PR, required CI, then merge. Use a separate git worktree for parallel branches.

## Rules that prevent mistakes
- **Secrets:** never read, print, log, commit, or paste a key. `.env.example` is names-only (a test enforces it); real values live in the Vercel secret store. The only secret is `RENTCAST_API_KEY`. Do not read `.env*` files.
- **One home, one unit:** never price or rent by room. No BUY/PASS verdicts: prices are calculations from the user's criteria.
- **Honest data:** every value is `retrieved | user | estimate | unavailable`. Never fill missing data with a default. State-average tax/insurance constants are unverified and low-confidence.
- **Sources:** only free public or licensed sources whose terms permit the use. No scraping listing sites (Zillow pages included), no unofficial endpoints. Zillow Research ZIP data needs attribution; RentCast needs the estimate disclaimer (already shown).
- **Tests never touch the network.** Live calls to paid APIs (RentCast: 50 requests/month, overage billed) are deliberate, counted, and rare.
- **Errors and logs:** no exception text, upstream bodies, addresses, or keys in responses or logs; upstream failures log source, status, and a strict short code only.
- `data/zip_market.json` is generated by `scripts/update_market_data.py`; never hand-edit.
- Do **not** add `pyproject.toml` (Vercel would install from it and skip `requirements.txt`, ADR-0004). Tool config lives in `ruff.toml`, `pytest.ini`, `.coveragerc`; `pytest.ini` keeps `--confcutdir=tests` so pytest does not scan the repo root. The coverage gate is a ratchet: raise it, never lower it.
- Dev server binds `127.0.0.1` unless `HOST` is set; CORS is off unless `CORS_ORIGINS` is set.
- Update `README.md`, `spec.md`, `plan.md`, and `intent.md` when behavior, limits, or decisions change.

## Map
`app.py` routes and error handling · `dealscope/` validation, provider (Census geocoder, ZIP data), homes (RentCast), analysis (price solver), service, config · `templates/` + `static/` UI · `data/` ZIP snapshot · `scripts/` smoke, data refresh, secret scan · `tests/` incl. golden vectors and repo-hygiene checks · `docs/` runbook, ADRs, AI-SDLC, `claude-config/` (hooks and skills you install yourself).

## Definition of done
Behavior implemented, failure behavior explicit, `make check` and CI green, docs accurate about what users can do and what is assumed or missing.
